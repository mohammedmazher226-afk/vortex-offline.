VORTEX 1.0

Made for your media.

Offline by design

Once a file has been imported successfully, VORTEX can play it without an internet connection, as long as browser storage remains available.

Storage and privacy

Media is stored locally in this browser's IndexedDB. Clearing Safari website data, deleting the web app's data, or uninstalling it may remove your library. Keep a separate backup of important files.

Important limitations

  • Large files may exceed iOS browser storage limits.
  • Direct URL downloads require a server that allows cross-origin requests.
  • Background downloads are not guaranteed when Safari is closed or suspended.
  • YouTube watch-page links are not direct media URLs.

Install on Home Screen

In Safari, tap Share, choose Add to Home Screen, then tap Add. Open VORTEX from the new Home Screen icon.
